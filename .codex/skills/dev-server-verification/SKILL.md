# 개발서버 검증

## 확인 대상

프로젝트마다 값이 다르므로 먼저 실제 설정을 찾는다.

- 외부 도메인 또는 로컬 URL
- 백엔드 내부 포트
- 프론트 dev server 포트
- 웹서버 프록시 설정
- systemd 또는 프로세스 매니저 서비스명
- 로그 위치

## 점검 순서

1. `ss -ltn` 등으로 내부 포트가 열렸는지 확인한다.
2. `curl -I`로 내부 포트 또는 도메인 상태를 확인한다.
3. 백엔드 변경이면 백엔드 로그에서 재시작/컴파일 성공 여부를 확인한다.
4. 프론트 변경이면 프론트 로그와 브라우저 반영을 확인한다.
5. systemd, Apache, Nginx 변경은 사용자의 sudo 적용 여부를 확인한다.

## 보고

- 확인한 서비스/URL
- 성공/실패 상태
- 실패 시 가장 가까운 로그 위치
- 사용자가 직접 sudo로 해야 할 작업
