프로그램 상세 내용

스토리 소개

태화강을 해마다 찾아오던 흰뺨검둥오리가 기후변화로 살기 어려워졌습니다. 계절이 뒤섞이고 먹이도 사라져 더 이상 머물 수 없게 된 거예요.
기후수사대가 되어 울산과 지구의 기후변화 원인을 조사하고, 건강한 기후를 되돌릴 수 있는 실천 방법을 찾아보세요.

연계 SDGs

SDGs 13 기후변화 대응

미션 구성

  • MISSION1

    기후수사대가 되어 울산, 우리나라, 지구의 기후변화 원인을 조사하세요.

  • MISSION2

    기후를 다시 건강하게 되돌릴 수 있는 실천 방법을 찾아 행동하세요.

이동 동선

  • 4개 동선 중 1개 선택, 5명씩 분산 배치 (지구존 → 미래존 → 사회존 → 도서관 순서 팀별로 상이)
  • 시작 → 종료 : 별관 러닝도서관 → ESD체험터·야외 → 별관 러닝도서관
